Tentang MEKA

Platform belajar Teknik Kontrol Mekatronika.

MEKA adalah platform pembelajaran interaktif untuk jurusan Teknik Kontrol Mekatronika (TKM) SMK Negeri 56. Website ini dibuat untuk membantu siswa memahami dasar sistem digital, gerbang logika, aljabar Boolean, tabel kebenaran, hingga pengenalan rangkaian kombinasional — lengkap dengan simulator interaktif dan kuis untuk menguji pemahaman.

Dibangun murni menggunakan HTML, CSS, dan JavaScript (tanpa framework) agar ringan dan mudah di-hosting lewat GitHub Pages. Progress belajar, XP, level, dan riwayat kuis disimpan langsung di browser masing-masing pengguna menggunakan localStorage — tanpa perlu akun atau server.
